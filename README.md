## Проекты

### [Ночной калейдоскоп](kaleidoscope/index.html)

Рисовалка с зеркалами: ведите мышью или пальцем по холсту, и линия повторится в каждом секторе. Пока вы не начали рисовать, узор выводит автопилот.

Горячие клавиши:

| Клавиша | Действие |
| --- | --- |
| `1`–`5` | число секторов: 3, 4, 6, 8, 12 |
| `M` | включить или выключить зеркала |
| `F` | угасание узора |
| `Пробел` | автопилот |
| `C` | очистить холст |
| `S` | сделать снимок |
| `Esc` | закрыть снимок |
